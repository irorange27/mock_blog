alphaTex 是 alphaTab 的纯文本记谱格式，适合在博客里放短乐句。语法是「时值 音符1 音符2 …」，音符写作「品位.弦」。下面六个例子从简到繁，每个都是真实乐句，能直接播放。

## 单音旋律：欢乐颂

最基础的写法：时值前缀 + 品位.弦。`:4` 四分音符，`:2` 二分音符。

::gp-score

```
\title "欢乐颂"
\tempo 120
.
:4 7.3 7.3 8.3 10.3 10.3 8.3 7.3 5.3 3.3 3.3 5.3 7.3 7.3 5.3 :2 5.3
```

::

## 和弦进行：C - Am - F - G

同一拍上的多个音符用括号包起来。C 大调最常用的进行，每个和弦四拍。

::gp-score{layout="tab"}

```
\title "C - Am - F - G"
\tempo 100
.
:4 (3.5 2.4 0.3 1.2) (3.5 2.4 0.3 1.2) (3.5 2.4 0.3 1.2) (3.5 2.4 0.3 1.2) | (0.5 2.4 2.3 1.2 0.1) (0.5 2.4 2.3 1.2 0.1) (0.5 2.4 2.3 1.2 0.1) (0.5 2.4 2.3 1.2 0.1) | (1.6 3.5 3.4 2.3 1.2 1.1) (1.6 3.5 3.4 2.3 1.2 1.1) (1.6 3.5 3.4 2.3 1.2 1.1) (1.6 3.5 3.4 2.3 1.2 1.1) | (3.6 2.5 0.4 0.3 0.2 3.1) (3.6 2.5 0.4 0.3 0.2 3.1) (3.6 2.5 0.4 0.3 0.2 3.1) (3.6 2.5 0.4 0.3 0.2 3.1)
```

::

## 技巧：击弦与滑音

技巧写在音符后的花括号里：击弦 `{h}`（从本音击到下一音）、滑音 `{sl}`（从本音滑到下一音）。

::gp-score{layout="tab"}

```
\title "电动少女"
\tempo 120
.
:16 0.4{h} 4.4 :16 r :16 5.2 :8 r :16 6.3 :16 r :8 7.4{sl} 9.4 :4 r | :16 0.4{h} 4.4 :16 r :16 5.2 :8 r :16 6.3 :16 r :8 7.4{sl} 9.4 :4 r | :16 6.4{sl} 7.4 :16 r :16 9.2 :8 r :8 9.3 :8 9.4{sl} 7.4 :4 r | :16 6.4{sl} 7.4 :16 r :16 9.2 :8 r :8 9.3 :8 9.4{sl} 11.4 :4 r
```

::

## 鼓轨：基本摇滚节奏

鼓用 `\instrument percussion` 声明，音符直接写 MIDI 鼓编号：36 底鼓、38 军鼓、42 踩镲。

::gp-score

```
\title "摇滚节奏"
\tempo 120
\instrument percussion
.
:8 42 36 42 38 42 36 42 38 42 36 42 38 42 38 46 46
```

::

## 多轨：Weird Fishes/Arpeggi 前奏

多轨用 `\track` 分隔。Jonny Greenwood 的吉他走高把位分解，Colin Greenwood 的贝斯走根音。和弦走向 Em7 - F#m7 - A - A7 - A6 - Gmaj7。25 钢弦吉他，33 指弹贝斯（贝斯只有四弦）。

::gp-score{tracks="all"}

```
\title "Weird Fishes/Arpeggi"
\tempo 120
\track
\instrument 25
.
:8 12.1 12.2 14.3 14.4 14.3 12.2 12.1 12.2 | 14.1 14.2 16.3 16.4 16.3 14.2 14.1 14.2 | 12.1 13.2 14.3 14.4 14.3 13.2 12.1 13.2 | 12.1 13.2 14.3 14.4 14.3 13.2 12.1 13.2
\track
\instrument 33
.
:4 2.4 4.4 7.4 5.4 | :4 2.4 4.4 7.4 5.4
```

::

## 完整小曲：小星星变奏

`\ro` 和 `\rc 2` 控制反复（重复两遍），`\ts 4 4` 拍号，`\ks C` 调号。

::gp-score

```
\title "小星星"
\artist "法国民谣"
\tempo 104
\ts 4 4
\ks C
\clef G2
.
\ro
:4 0.3 0.3 7.3 7.3 8.3 8.3 :2 7.3
\rc 2
:4 5.3 5.3 3.3 3.3 2.3 2.3 :2 0.3
```

::

更多语法（连音、装饰音、歌词、速度变化、拍号变化等）见 [alphaTex 官方文档](https://www.alphatab.net/docs/alphatex/introduction)。
